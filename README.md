# NeoNotes (Tkinter)

Приложение заметок с дедлайнами, архивом, тегами, поиском, сортировкой и экспортом.

## Возможности
- Создание/изменение/удаление заметок.
- Название, текст, дата заметки, дата создания/изменения.
- Дедлайн и продление дедлайна (+1 день).
- Архивирование и фильтр показа архива.
- Экспорт/импорт JSON.
- Локальные бэкапы.
- Поиск по названию/тексту/тегам, сортировки.
- Простое форматирование выделенного текста: жирный/курсив/обычный.
- Полноэкранный визуальный календарь дедлайнов (через `tkcalendar`, если установлен).
- Напоминания о дедлайнах за 10 минут (встроенный фоновый поток).
- Заглушки под OAuth-бэкапы в Google Drive/Dropbox.

## Запуск
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

## Примечания
- Для Google Drive/Dropbox нужны отдельные OAuth credentials и интеграция API.
- Если `tkcalendar` не установлен, окно календаря покажет fallback-список дедлайнов.
